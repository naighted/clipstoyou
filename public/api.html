Flujo completo: 9:16 y dividir en partes

Full flow: 9:16 and split into parts

1. POST /convertir-916

Sube el vídeo (multipart, campo video, hasta 4 GB) y elige el modo con modoCam:

Upload the video (multipart, field video, up to 4 GB) and pick the mode with modoCam:

  • blur: vídeo completo centrado con fondo desenfocado. No necesita más parámetros. Es el modo recomendado para automatizar.
  • sin-cam: recorte a pantalla completa. Opcional: cropX, cropY, cropW, cropH (píxeles del vídeo original).
  • con-cam: cámara arriba o abajo y juego en la otra mitad. Obligatorio: camX, camY, camW, camH, videoW, videoH. Opcional: camPosicion (arriba | abajo), gpX, gpY, gpW, gpH.
  • blur: full video centered over a blurred background. No extra parameters. Recommended for automation.
  • sin-cam: full-screen crop. Optional: cropX, cropY, cropW, cropH (pixels of the original video).
  • con-cam: webcam on top or bottom, gameplay in the other half. Required: camX, camY, camW, camH, videoW, videoH. Optional: camPosicion (arriba = top | abajo = bottom), gpX, gpY, gpW, gpH.
curl -X POST https://www.clipstoyou.com/convertir-916 \
  -H "Authorization: Bearer $CLIPSTOYOU_KEY" \
  -F "video=@mi_video.mp4" \
  -F "modoCam=blur"

# → {"jobId":"lx3k9abc12"}

2. GET /api/job916/{jobId}

Consulta cada 5–10 segundos hasta que status sea done o error. Al terminar devuelve la duración en segundos para calcular las partes.

Poll every 5–10 seconds until status is done or error. When done it returns the duration in seconds so you can work out the parts.

curl https://www.clipstoyou.com/api/job916/lx3k9abc12 \
  -H "Authorization: Bearer $CLIPSTOYOU_KEY"

# → {"status":"done","error":null,"duracionSegundos":754}

3a. POST /dividir-desde-916/{jobId}

Divide el vídeo ya convertido sin volver a subirlo. duracion = segundos de cada parte. Para N partes iguales usa ceil(duracionSegundos / N). Envía Accept: application/json para recibir un enlace de descarga.

Split the converted video without uploading it again. duracion = seconds per part. For N equal parts use ceil(duracionSegundos / N). Send Accept: application/json to receive a download link.

curl -X POST https://www.clipstoyou.com/dividir-desde-916/lx3k9abc12 \
  -H "Authorization: Bearer $CLIPSTOYOU_KEY" \
  -H "Content-Type: application/json" \
  -H "Accept: application/json" \
  -d '{"duracion": 60}'

# → {"downloadUrl":"/descargas-partes/3f2c…","partes":13}

3b. GET /api/job916/{jobId}/download

Si solo quieres el vídeo 9:16 entero, sin dividir.

If you only want the whole 9:16 video, not split.

curl -L -o video_9_16.mp4 https://www.clipstoyou.com/api/job916/lx3k9abc12/download \
  -H "Authorization: Bearer $CLIPSTOYOU_KEY"

4. GET {downloadUrl}

Descarga el ZIP con las partes ordenadas (nombre - parte 1.mp4, parte 2…).

Download the ZIP with the ordered parts (name - parte 1.mp4, parte 2…).

curl -L -o partes.zip https://www.clipstoyou.com/descargas-partes/3f2c… \
  -H "Authorization: Bearer $CLIPSTOYOU_KEY"

POST /dividir

Divide un vídeo sin convertirlo a 9:16. Multipart con video y duracion; con Accept: application/json devuelve downloadUrl igual que el paso 3a.

Split a video without converting it to 9:16. Multipart with video and duracion; with Accept: application/json it returns downloadUrl like step 3a.

Caducidad y errores

Expiry and errors

  • Los vídeos convertidos y los ZIP se borran del servidor a los 30 minutos. Descárgalos antes.
  • 401 clave inválida o revocada · 403 tu plan no incluye la API · 429 límite del plan alcanzado · 404 trabajo o descarga caducados.
  • Todas las respuestas de error son JSON: {"error": "mensaje"}.
  • Converted videos and ZIPs are deleted from the server after 30 minutes. Download them before that.
  • 401 invalid or revoked key · 403 your plan doesn't include the API · 429 plan limit reached · 404 job or download expired.
  • All error responses are JSON: {"error": "message"}.

Usarlo con Claude o ChatGPT

Using it with Claude or ChatGPT

Instala el conector de ClipsToYou en tu app de escritorio (Claude Desktop, ChatGPT Desktop u otra compatible con MCP). La IA podrá coger vídeos de tus carpetas, convertirlos a 9:16, dividirlos y dejar los clips en tu PC, y combinarlo con otras herramientas que tengas conectadas, como tu app para programar publicaciones.

Install the ClipsToYou connector in your desktop app (Claude Desktop, ChatGPT Desktop or any other MCP-compatible app). The AI will be able to pick videos from your folders, convert them to 9:16, split them and leave the clips on your PC, and combine that with other tools you have connected, like your post-scheduling app.

1. Requisito: Node.js

1. Requirement: Node.js

Instala Node.js 20 o superior (versión LTS).

Install Node.js 20 or newer (LTS version).

2. Añade el conector

2. Add the connector

En Claude Desktop: Configuración → Desarrollador → Editar configuración, y añade esto con tu clave:

In Claude Desktop: Settings → Developer → Edit Config, and add this with your key:

{
  "mcpServers": {
    "clipstoyou": {
      "command": "npx",
      "args": ["-y", "clipstoyou-mcp"],
      "env": { "CLIPSTOYOU_API_KEY": "ctu_tu_clave" }
    }
  }
}

Reinicia la app. En otras apps compatibles con MCP usa el mismo comando (npx -y clipstoyou-mcp) y la variable CLIPSTOYOU_API_KEY.

Restart the app. In other MCP-compatible apps use the same command (npx -y clipstoyou-mcp) and the CLIPSTOYOU_API_KEY variable.
